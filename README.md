# WebGL2 过山车轨道编辑器

一个基于纯WebGL2实现的过山车轨道编辑器，使用3D贝塞尔曲线动态生成平滑的过山车轨道。无需Unity3D，文件体积小，性能优秀。

## 功能特性

- 🎢 **3D贝塞尔曲线编辑器**：在浏览器中直观地编辑曲线
- 🔄 **切线方向约束**：每个控制点左右两侧切线共用一条单位方向向量，长度可独立调整，保证局部光滑
- 🛤️ **自动轨道生成**：根据样条自动生成 3D 轨道网格（含木架多网格轨道）
- 🎨 **实时预览**：编辑模式下渲染曲线预览线：正常曲率为黄色、曲率过大段为红色
- 🚉 **固定站台系统**：轨道起点固定为水平站台段，小车到达站台末端后自动停靠 10 秒并以 1 m/s 匀速牵引离站
- 🚗 **物理模拟**：真实的过山车物理模拟，包括速度、加速度、G 力、急动度等
- 📊 **实时数据监控**：显示速度、加速度、G 力、尖叫指数等专业指标
- 🎮 **过山车类型系统**：多种过山车类型（木架 / 钢架 / 现代），逐步解锁升级
- ⚡ **电磁牵引系统**：现代过山车支持电磁加速和减速
- ✏️ **控制点详细编辑面板**：可精确编辑选中控制点的坐标、左右切线方向（单位向量）与长度
- 🧠 **曲线保持算法**：使用 de Casteljau 细分算法插入控制点，保证添加新点时曲线形状不变
- 📱 **响应式设计**：支持桌面和移动设备
- 🚀 **轻量级**：纯 WebGL2 实现，无需 Unity，文件体积小

## 游戏流程

### 🎯 游戏目标

设计并优化过山车轨道，创造刺激、安全、有趣的过山车体验。通过完成轨道设计，解锁更高级的过山车类型，获得更多设计工具和更高的性能限制。

### 📋 游戏阶段

#### 第一阶段：木架过山车（初始解锁）

**特性：**
- 最大高度：30米
- 最大速度：25 m/s
- 最大G力：3.5G
- 功能：牵引到顶、自由滑下

**玩法：**
1. 使用3D编辑器设计过山车轨道
2. 设置牵引区域（按 `L` 键或点击按钮），让小车从底部被牵引到顶部
3. 小车从顶部自由滑下，体验重力驱动的刺激
4. 观察实时物理数据：速度、加速度、G力等
5. 优化轨道设计，确保安全性和刺激性

**目标：**
- 完成一个完整的过山车轨道设计
- 确保轨道曲率连续，不会过于陡峭
- 观察物理数据，确保G力在安全范围内

#### 第二阶段：钢架过山车（升级解锁）

**特性：**
- 最大高度：100米（提升3.3倍）
- 最大速度：50 m/s（提升2倍）
- 最大G力：5.0G
- 功能：牵引到顶、自由滑下、更高速度、更高高度

**玩法：**
1. 点击"升级到下一阶段"按钮解锁钢架过山车
2. 利用更高的高度限制，设计更刺激的轨道
3. 可以建造更高的爬坡和更快的速度
4. 体验更强烈的G力和更刺激的体验
5. 继续优化轨道设计

**目标：**
- 充分利用新的高度和速度限制
- 设计更复杂的轨道布局
- 平衡刺激性和安全性

#### 第三阶段：现代过山车（最终解锁）

**特性：**
- 最大高度：150米（提升5倍）
- 最大速度：70 m/s（提升2.8倍）
- 最大G力：6.0G
- 功能：牵引到顶、自由滑下、**电磁加速**、**电磁减速**、更高速度、更高高度

**玩法：**
1. 点击"升级到下一阶段"按钮解锁现代过山车
2. 使用电磁加速系统（按 `B` 键）：
   - 在轨道任意位置设置加速点
   - 调整目标速度（最高70 m/s）
   - 小车经过时会自动加速到目标速度
3. 使用电磁减速系统（按 `N` 键）：
   - 在需要减速的位置设置减速点
   - 调整减速度
   - 小车经过时会自动减速
4. 设计复杂的轨道：
   - 多个加速点提升速度
   - 在转弯前减速确保安全
   - 创造更丰富的体验
5. 监控专业指标：
   - 尖叫指数（Scream Index）
   - 刺激指数（Thrill Index）
   - 舒适指数（Comfort Index）
   - 安全指数（Safety Index）

**目标：**
- 充分利用电磁牵引系统
- 设计最刺激、最安全的过山车
- 优化各项专业指标

### 🎮 操作指南

#### 轨道编辑

1. **选择控制点**：点击 3D 视图中的控制点（默认黄色）
2. **移动控制点**：
   - 直接拖动：自由移动
   - 点击箭头拖动：沿 X / Y / Z 轴约束移动
   - 左侧“控制点坐标 (X/Y/Z)”输入框：精确数值编辑
3. **调整曲线形状 / 切线**：
   - 拖动青色 / 蓝色切线控制点调整方向和长度
   - 左侧“左/右切线方向 (单位向量)”输入框：精确修改方向
   - “切线长度”滑块：调整左右切线长度（不会改变方向）
4. **添加控制点**：
   - 选中控制点后，点击“添加控制点”按钮
   - 使用弹出的滑条（0–1）调整插入位置
   - 内部使用 de Casteljau 细分算法，**保证添加前后曲线形状完全一致**
5. **删除控制点**：
   - 点击“删除选中点”按钮
   - **说明：为避免误删，键盘 Delete / Backspace 等全局快捷键已关闭**

#### 相机控制

- **缩放**：鼠标滚轮或双指缩放
- **旋转**：在空白处拖动鼠标
- **重置相机**：点击"重置相机"按钮

#### 特殊区域设置

1. **固定站台区域**（所有类型，共用）：
   - 站台位置固定为：尾部 `(-L, 5, 0)`，头部 `(0, 5, 0)`，水平方向沿 +X
   - 站台控制点在编辑器中不可移动，其相邻非站台控制点可以自由调整
   - 小车到达站台末端自动停靠 10 秒，然后以 1 m/s 匀速被牵引离站

2. **牵引区域**（所有类型，除站台外的普通牵引）：
   - 在“编辑”面板中选中控制点
   - 点击“切换牵引区域”按钮
   - 控制点显示为橙色
   - 小车在此区域保持匀速运动

3. **电磁加速**（仅现代过山车）：
   - 选中控制点，点击“电磁加速”按钮
   - 控制点显示为蓝色
   - 使用滑条调整加速度

4. **电磁减速**（仅现代过山车）：
   - 选中控制点，点击“电磁减速”按钮
   - 控制点显示为红色
   - 使用滑条调整减速度

## 技术说明

### 贝塞尔曲线

使用三次贝塞尔曲线（Cubic Bezier Curve）连接控制点，每个曲线段由4个点定义：
- 起点（P0）
- 起点右侧控制点（P1）
- 终点左侧控制点（P2）
- 终点（P3）

### 切线与曲率

- 每个控制点内部使用：**单位切线方向 + 左右两侧切线长度** 的表示方式：
  - 左右切线始终共线、方向相反，长度可以独立调整
  - UI 中的“切线方向”编辑的是这条单位向量，“切线长度”编辑的是左右长度
- 引擎不再强制全局 C2 连续（不过度自动改动相邻控制点）：
  - 控制点的切线不会被“自动修正”成某种理想形状，完全由你控制
  - 当曲率过大时，**只在编辑预览中用红色线段标记出来**，不会自动修改数据

### 轨道生成

轨道生成过程：

1. 沿曲线采样多个点
2. 为每个采样点计算局部坐标系（切线、法线、副法线）
3. 使用局部坐标系生成横截面
4. 连接横截面形成轨道网格
5. 可选地生成护栏

### WebGL2 渲染

- 使用WebGL2进行硬件加速渲染
- 支持光照和阴影
- 实时更新网格数据

## 开发说明

### 核心类

#### BezierSpline
贝塞尔曲线核心类，提供：
- `addPoint(position)` - 添加控制点
- `removePoint(index)` - 移除控制点
- `getPoint(t)` - 获取曲线上参数t处的点（t范围0-1）
- `getTangent(t)` - 获取切线方向
- `ensureC2Continuity(index)` - 确保C2连续性

#### TrackGenerator
轨道网格生成器：
- `generateTrack()` - 生成轨道网格数据
- 可配置的轨道参数

#### Renderer
WebGL2渲染器：
- `setTrackMesh(meshData)` - 设置轨道网格
- `setCurveLineMesh(points)` - 设置曲线线条
- `render()` - 渲染场景

#### Editor
交互式编辑器：
- 处理鼠标/触摸输入
- 管理控制点选择
- 更新轨道网格
