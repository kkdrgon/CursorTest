# 椭圆岛地图 HTML Demo

`web/` 目录包含一个可直接打开的 Canvas 演示，用于预览 400m×300m 椭圆岛地图、刷点分布、主要路径、静态障碍以及抛物线射击模拟。

## 快速开始
### 方式一：本地静态服务器
```bash
npm install
npm run dev   # or npm start
# 浏览器访问 http://localhost:3000
```

### 方式二：直接打开文件
双击 `web/index.html`（部分浏览器出于安全策略可能需使用方式一）。

运行后可在右侧面板调整图层、速度/角度，或点击画布改变发射起点；观察信息面板与事件记录，了解箭矢命中的层级（地形/海水/障碍/崖壁）。

## 主要功能
- 椭圆岛底图 + 分区遮罩 + 网格坐标参考。
- 4 条主路径和动态刷点组合显示。
- 障碍/崖壁碰撞体积可视化。
- 职业技能模拟：弓箭手（抛物线）、战士（近战斩击）、法师（火球术/陨石术）。
- 各技能支持自定义参数（速度、仰角、方位角、目标距离）并输出命中反馈与覆盖区域。
- 法师可在「结印手势」面板绘制「▽」形结印：拟合度越高，法术威力越强；结印后保持原地可让火球术连发。

## 移动端适配
- 页面在 <=900px 宽度时自动改为纵向布局，Canvas 高度按视口缩放。
- 右上角提供“折叠面板”按钮，可隐藏调试控件，仅保留画布。
- Canvas 支持触屏点击（Pointer 事件）调整发射点，避免 300ms 延迟；控件与按钮增大间距便于手指操作。
