# 椭圆岛地图 HTML Demo

`web/` 目录包含一个可直接打开的 Canvas 演示，用于预览 400m×300m 椭圆岛地图、刷点分布、主要路径、静态障碍以及抛物线射击模拟。

## 快速开始
### 方式一：本地静态服务器
```bash
npm install
npm run dev   # or npm start
# 浏览器访问 http://localhost:3000
```

### 方式二：直接打开文件
双击 `web/index.html`（部分浏览器出于安全策略可能需使用方式一）。

运行后可在右侧面板调整图层、速度/角度，或点击画布改变发射起点；观察信息面板与事件记录，了解箭矢命中的层级（地形/海水/障碍/崖壁）。

## 开发文档
- `docs/map_prototype.md`：地图与碰撞设计概要。
- `docs/web_map_design.md`：Web 实现设计方案（HTML + JS）。

## 主要功能
- 椭圆岛底图 + 分区遮罩 + 网格坐标参考。
- 4 条主路径和动态刷点组合显示。
- 障碍/崖壁碰撞体积可视化。
- 抛物线射线模拟（自定义速度、仰角、方位角）与命中反馈。
