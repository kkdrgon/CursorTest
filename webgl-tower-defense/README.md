# WebGL2 塔防游戏

这是一个使用 WebGL2 片元着色器进行游戏逻辑计算的塔防游戏。游戏逻辑从 Web Worker 迁移到了 GPU 计算，以提高性能。

## 项目结构

```
webgl-tower-defense/
├── index.html          # 主HTML文件
├── main.js             # 主入口文件
├── game.js             # 游戏核心逻辑
├── shaders/
│   ├── compute.frag    # 计算着色器（游戏逻辑）
│   ├── render.vert     # 渲染顶点着色器
│   └── render.frag     # 渲染片元着色器
├── assets/
│   └── abc.png         # 纹理图集（需要从原项目复制）
└── README.md           # 本文件
```

## 技术特点

1. **GPU 计算**：使用 WebGL2 片元着色器进行游戏逻辑计算，包括：
   - 塔的瞄准和射击
   - 敌人的移动和寻路
   - 子弹的移动和碰撞检测
   - 游戏状态更新

2. **乒乓缓冲**：使用双纹理缓冲技术实现计算结果的交换

3. **统一缓冲区对象（UBO）**：使用 UBO 传递游戏状态和路径数据

## 运行方法

1. 将原项目的 `abc.png` 文件复制到 `assets/` 目录
2. 使用支持 ES6 模块的现代浏览器打开 `index.html`
3. 或者使用本地服务器运行（推荐）：
   ```bash
   # 使用 Python
   python -m http.server 8000
   
   # 使用 Node.js
   npx http-server
   ```
4. 在浏览器中访问 `http://localhost:8000/webgl-tower-defense/`

## 游戏操作

- **建造塔**：从右侧工具栏拖拽塔到地图上
- **选择塔**：点击地图上的塔
- **升级塔**：选择塔后点击左侧的 "update" 按钮
- **删除塔**：选择塔后点击左侧的 "delete" 按钮
- **下一波**：点击 "Next" 按钮提前开始下一波敌人

## 开发说明

### 计算着色器逻辑

计算着色器 (`compute.frag`) 负责处理所有游戏逻辑：
- 第 0 行：塔数据
- 第 1-8 行：敌人数据
- 第 9 行：子弹计数
- 第 10-24 行：子弹数据
- 第 25 行：游戏状态数据

### 数据编码

游戏单位数据使用位编码存储在 RGBA32UI 纹理中：
- `x, y`：位置（使用 floatBitsToUint 编码）
- `z`：方向（10位）+ ticksFlag（19位）
- `w`：isUsed（1位）+ id（8位）+ a（4位）+ b（18位）

### 路径查找

路径查找在 CPU 端完成，通过 UBO 传递给 GPU。路径数据存储在 `path` 数组中，每个路径 1500 个点。
