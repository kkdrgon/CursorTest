# RSA 小课程工具

面向小学阶段的迷你 Web 演示，通过四个循序渐进的环节帮助孩子动手理解 RSA 基本流程：

| 环节 | 说明 |
| --- | --- |
| 1. 选素数 | 从预设的两位数素数列表中挑选两个数字，生成 `n` 与欧拉函数 `φ(n)` |
| 2. 定公钥 | 从候选集合挑选公开指数 `e`，系统即时判断是否与 `φ(n)` 互质 |
| 3. 算私钥 | 使用扩展欧几里得算法求得私钥指数 `d`，集中展示所有关键数值 |
| 4. 玩加密 | 输入英文或数字，点击“加密 / 解密”即可查看明文与密文的互转 |

---

## 快速上手

1. 直接在浏览器中打开 `index.html`（纯前端，无需构建）。  
2. 按界面提示依序完成 4 个步骤，切换素数或 `e` 后记得点击“更新密钥”。  
3. 在“消息”框中输入文本，依次点击“加密”“解密”即可观察结果。  
4. 将鼠标悬停在提示图标上可查看术语释义，方便课堂讲解。

---

## 技术要点与安全提示

- 纯原生 HTML / CSS / JavaScript，实现轻量、易部署。  
- `script.js` 内置素数列表、模幂运算与扩展欧几里得算法，负责求解 `d` 并执行加解密。  
- 为教学安全，仅允许两位数素数，**请勿用于真实安全需求**。
