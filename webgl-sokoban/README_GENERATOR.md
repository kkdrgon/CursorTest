# 推箱子关卡生成器使用说明

## 功能特点

- ✅ 自动生成推箱子关卡
- ✅ 验证关卡是否可解
- ✅ **验证关卡是否有唯一解**（这是关键特性）
- ✅ 支持地面坑洞（箱子可以填坑）
- ✅ 自动保存为 JS 和 JSON 格式

## 使用方法

### 基本用法

在 `webgl-sokoban` 目录下运行：

```bash
python generate_levels.py
```

默认会生成 5 个唯一解关卡。

### 自定义参数

```bash
python generate_levels.py [关卡数量] [每个关卡最大尝试次数] [固定尺寸(可选)]
```

例如：
```bash
# 生成 10 个关卡，每个最多尝试 300 次，随机尺寸（支持非方形）
python generate_levels.py 10 300

# 生成 3 个关卡，每个最多尝试 100 次（更快）
python generate_levels.py 3 100

# 生成 5 个固定尺寸的关卡（8x10 矩形）
python generate_levels.py 5 200 8x10

# 生成 5 个固定尺寸的关卡（10x6 横矩形）
python generate_levels.py 5 200 10x6
```

### 支持的关卡尺寸

生成器支持多种尺寸组合，包括：
- **方形**: 6x6, 7x7, 8x8, 9x9
- **竖矩形**: 6x8, 7x9, 6x10, 8x10, 7x11
- **横矩形**: 8x6, 9x7, 10x6, 10x8, 11x7

如果不指定固定尺寸，生成器会随机选择不同的尺寸组合，让关卡更加多样化。

## 生成的文件

- `src/generated_levels.js` - JS 格式的关卡文件（游戏会自动加载）
- `generated_levels.json` - JSON 格式的关卡文件（备用）

## 关卡参数

关卡生成器遵循以下约束：

1. **箱子数量 = 目标点数量 + 坑数量**
   - 例如：2 个目标点 + 1 个坑 = 3 个箱子
   - 这意味着必须填坑才能让所有箱子到达目标点

2. **在不填坑的情况下，箱子不能到达目标点**
   - 生成器会验证：如果将所有坑视为墙（不可走），箱子无法到达所有目标点
   - 这确保了玩家必须填坑才能通关

可以在 `generate_levels.py` 的 `get_level_params_for_size()` 函数中修改参数计算逻辑。

## 唯一解验证

生成器会：
1. 首先生成一个可解的关卡
2. 然后验证该关卡是否只有**唯一解**
3. 如果有多条路径可以通关，会丢弃并重新生成

这确保了生成的关卡具有挑战性，玩家必须找到正确的路径才能通关。

## 注意事项

- 唯一解验证需要较长时间（每个关卡可能需要几秒到几十秒）
- 如果生成失败，可以：
  - 减少 `num_boxes`（箱子越少越容易生成）
  - 增加 `max_attempts`（尝试更多次）
  - 减少 `wall_density`（墙越少空间越大）

## 游戏中使用

生成的关卡会自动加载到游戏中。刷新浏览器页面后，新生成的关卡会出现在关卡列表中。
