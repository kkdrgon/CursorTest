# WebGL2 多人联网战斗游戏（3D 第一人称）

基于 WebGL2 的实时多人射击体验，支持桌面与移动端输入、程序化岛屿地图和服务端权威同步。

## ✨ 核心亮点

| 领域 | 细节 |
| --- | --- |
| 对战体验 | 实时 WebSocket 同步 · 客户端预测 · 200ms 射击冷却 · 100HP / 10HP 伤害 |
| 地图/渲染 | WebGL2 自研渲染管线 · 程序化随机小岛 + 水面 · 法线/光照修正 · 动态障碍物 |
| UI/反馈 | 第一人称武器模型 · 准星 · 击杀提示 · 计分板（K/D/KD）· 迷你小地图 · FPS HUD |
| 输入支持 | 桌面（鼠标+键盘） · 移动端虚拟摇杆+触摸视角+按钮射击 |

## 🚀 快速开始

```bash
npm install      # 安装依赖
npm start        # 启动服务器（默认 http://localhost:3000）
```

在浏览器中打开多个标签页或不同设备即可联机测试。

## 🎮 操作说明

**桌面端**
- `WASD / 方向键`：移动
- 鼠标移动：视角
- 鼠标左键：射击
- `Space`：跳跃
- `R`：重生

**移动端 / 平板**
- 左下虚拟摇杆：移动
- 右侧触摸拖拽：视角
- 右下“射击”按钮：射击
- 状态栏点击：重生

## 🌍 世界与机制

- 每名玩家：`100 HP`，命中 -10 HP，死亡可手动重生
- 程序化岛屿：Sin/Cos 噪声生成多边形海岛，周围为水域，自动铺设树木、岩石、遗迹
- 服务端判定玩家/子弹是否留在岛上，离开即阻止或销毁
- 障碍物随机分布并匹配地形高度，提供掩体
- 小地图显示岛屿轮廓、敌我位置、朝向和障碍物

## 📁 项目结构

```
webgl-multiplayer-battle/
├── index.html          # 游戏入口 + 虚拟摇杆 UI
├── client.js           # 客户端引导
├── game.js             # 玩法逻辑、UI 更新、程序化岛屿
├── renderer.js         # WebGL2 渲染器、地形网格
├── math3d.js           # 向量/矩阵运算
├── network.js          # WS 封装
├── server.js           # Node.js + ws 权威服务器
└── README.md
```

## 🧰 技术栈

- 前端：WebGL2、原生 ES Modules、定制 3D 数学库
- 后端：Node.js + Express + ws
- 网络：WebSocket 双向通信（JSON 协议）
- 地图：客户端生成地形网格，服务端复用同套噪声逻辑校验位置

## 📱 移动端优化

- `touch-action: none` + 阻止默认滚动
- 虚拟摇杆 + 按钮半透明玻璃风格
- HUD 自适应：生命条、计分板、迷你地图、武器 Canvas 动态缩放

## 🧠 开发提示

- 客户端预测 + 服务器纠偏：`game.js` 中插值本地玩家位置，非本地玩家直接跟随状态包
- 地形高度/边界：`Game` 与 `server.js` 共用噪声函数，确保判定一致
- Renderer 内置法线矩阵与三角扇地形网格，可扩展贴图/阴影
- 可以通过调节噪声频率、障碍数量、HUD 样式等，快速产出不同主题的战斗场景
